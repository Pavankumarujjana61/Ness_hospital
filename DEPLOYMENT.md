# Hostinger Deployment Guide — NESHOSP

## Project Structure

```
NESHOSP/
├── dist/               ← React build output (generated by npm run build)
├── public/             ← Static images + uploaded doctor photos
├── server/
│   ├── server.js       ← Express backend (entry point)
│   └── db.js           ← MySQL connection
├── src/                ← React source code
├── .env                ← Environment variables (DO NOT commit)
├── .env.example        ← Template for env variables (safe to commit)
├── .htaccess           ← Proxies Apache → Node on port 3000
├── package.json
└── vite.config.js
```

---

## Step 1 — Create MySQL Database on Hostinger

1. Go to **hPanel → Databases → MySQL Databases**
2. Create a new database, e.g. `u123456_neshosp`
3. Create a database user and assign it to the database with **All Privileges**
4. Note down: `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`

> DB_HOST is usually `127.0.0.1` on Hostinger shared hosting.

---

## Step 2 — Set Up Node.js App on Hostinger

1. Go to **hPanel → Website → Node.js**
2. Click **Create Application**
3. Set these values:
   - **Node.js version**: 18 or higher
   - **Application root**: `/public_html` (or your domain folder)
   - **Application URL**: your domain
   - **Application startup file**: `server/server.js`
4. Click **Create**

---

## Step 3 — Upload Project Files

Upload everything **except** these folders/files:
- `node_modules/` (will be installed on server)
- `dist/` (will be built on server)
- `.env` (will be created manually on server)

You can use:
- **Hostinger File Manager** (hPanel → Files → File Manager)
- **FTP** with FileZilla using your Hostinger FTP credentials
- **Git** if your hosting plan supports SSH access

---

## Step 4 — Install Dependencies on Server

In **hPanel → Node.js → your app → Run NPM command**, run:

```
install
```

This runs `npm install` on the server.

---

## Step 5 — Build the React Frontend on Server

In **hPanel → Node.js → your app → Run NPM command**, run:

```
run build
```

This runs `npm run build` and generates the `dist/` folder.

---

## Step 6 — Set Environment Variables

In **hPanel → Node.js → your app → Environment Variables**, add:

| Key          | Value                              |
|--------------|------------------------------------|
| PORT         | 3000                               |
| DB_HOST      | 127.0.0.1                          |
| DB_PORT      | 3306                               |
| DB_USER      | your_db_username                   |
| DB_PASSWORD  | your_db_password                   |
| DB_NAME      | your_db_name                       |
| JWT_SECRET   | your-long-random-secret-string     |

> Alternatively, create a `.env` file in the app root via File Manager with the same values.

---

## Step 7 — Start the Application

In **hPanel → Node.js → your app**, click **Restart**.

The app will:
1. Connect to MySQL and auto-create all tables
2. Seed default admin (username: `admin`, password: `admin123`)
3. Serve the React frontend at your domain
4. Serve the API at `yourdomain.com/api/...`

---

## Step 8 — Verify Deployment

- Visit `https://yourdomain.com` — React frontend should load
- Visit `https://yourdomain.com/api/doctors` — should return JSON
- Visit `https://yourdomain.com/admin` — admin panel should load

## Local Development

```bash
# Install dependencies
npm install

# Run frontend + backend together
npm run dev

# Build frontend only
npm run build

# Run backend only
npm start
```

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Blank page on load | Run `npm run build` again, check dist/ folder exists |
| API returns 404 | Check Node.js app is running in hPanel |
| Database error | Verify DB credentials in environment variables |
| Images not loading | Check `public/` folder was uploaded |
| App won't start | Check Node.js version is 18+ in hPanel |
